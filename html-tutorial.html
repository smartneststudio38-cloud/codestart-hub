HTML Tutorial for Beginners

HTML is the basic language used to create the structure of webpages. If you are completely new to web development, HTML is a great place to start.

What is HTML?

HTML stands for HyperText Markup Language. It tells the browser how different parts of a webpage should be arranged.

Basic HTML Structure

Every HTML webpage usually starts with a basic document structure. 

<!DOCTYPE html>
<html>
<head>
    <title>My First Webpage</title>
</head>

<body>

    <h1>Hello World!</h1>
    <p>This is my first webpage.</p>

</body>
</html>

7 Basic HTML Tags

Here are some important HTML tags beginners should learn:

  • <h1> — Main heading
  • <p> — Paragraph
  • <a> — Link
  • <img> — Image
  • <ul> — Unordered list
  • <li> — List item
  • <button> — Button

Example: Heading and Paragraph

<h1>Welcome to My Website</h1>

<p>I am learning HTML as a beginner.</p>

How to Practice HTML

The best way to learn HTML is to practice by creating small webpages. Start with headings and paragraphs, then gradually add links, images, lists and buttons.

What Should You Learn Next?

After learning the HTML basics, the next step is CSS. CSS helps you add colors, spacing, layouts and attractive designs to your webpages.
