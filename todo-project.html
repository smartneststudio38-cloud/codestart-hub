To-Do List Project

A To-Do List is a simple JavaScript project that helps beginners practice HTML, CSS and JavaScript together.

What You Will Learn

  • Creating HTML input fields
  • Adding buttons
  • Using JavaScript events
  • Adding tasks dynamically
  • Practicing basic DOM manipulation

Step 1: Create the HTML

<input type="text" id="taskInput"
placeholder="Enter a task">

<button onclick="addTask()">
Add Task
</button>

<ul id="taskList"></ul>

Step 2: Add JavaScript

JavaScript can read the task entered by the user and add it to the list. 

function addTask() {

    let input = document.getElementById("taskInput");
    let task = input.value;

    if (task !== "") {

        let item = document.createElement("li");

        item.textContent = task;

        document.getElementById("taskList").appendChild(item);

        input.value = "";
    }
}

Step 3: Improve Your To-Do List

After creating the basic version, you can add more features to make your project more useful.

  • Add a delete button
  • Mark completed tasks
  • Add task editing
  • Save tasks using local storage
  • Improve the design with CSS

What Should You Practice Next?

Try changing the design and adding new features to your To-Do List. Building small projects is a good way to practice JavaScript.
