Personal Portfolio Website Project

A personal portfolio is a great first web development project. You can use it to introduce yourself, show your skills and display the projects you build while learning coding.

What You Will Learn

  • Basic HTML page structure
  • Headings and paragraphs
  • Links and sections
  • Basic CSS styling
  • How to organize a simple webpage

Step 1: Create the HTML

Start with a simple HTML structure for your portfolio. 

<!DOCTYPE html>
<html>
<head>
    <title>My Portfolio</title>
</head>

<body>

    <h1>My Portfolio</h1>

    <h2>About Me</h2>
    <p>I am learning web development.</p>

    <h2>My Skills</h2>
    <p>HTML, CSS and JavaScript</p>

</body>
</html>

Step 2: Add CSS

After creating the HTML structure, you can use CSS to improve the appearance of your portfolio. 

body {
    font-family: Arial, sans-serif;
    padding: 30px;
}

h1 {
    color: #2563eb;
}

h2 {
    margin-top: 30px;
}

Step 3: Add Your Information

Replace the example text with your own name, skills and project information. You can also add links to your social profiles or other websites.

How to Improve Your Portfolio

  • Add a profile image
  • Create a projects section
  • Add a contact section
  • Make the design responsive
  • Practice different CSS layouts

What Should You Build Next?

Once you finish your portfolio, try building a to-do list or another JavaScript project to practice interactive features.
