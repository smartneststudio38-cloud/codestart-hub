CSS Tutorial for Beginners

CSS is used to style and design webpages. After learning HTML, CSS is the next important skill for creating attractive websites.

What is CSS?

CSS stands for Cascading Style Sheets. It controls how HTML elements look on a webpage, including colors, fonts, spacing, borders and layouts.

How CSS Works

CSS selects an HTML element and tells the browser how that element should look. 

p {
    color: blue;
    font-size: 18px;
}

Changing Text Color

You can use the color property to change the color of text. 

h1 {
    color: green;
}

Changing Background Color

The background-color property lets you add a background color to an HTML element. 

body {
    background-color: lightgray;
}

Adding Spacing

CSS provides padding and margin to control space around elements. 

.box {
    padding: 20px;
    margin: 20px;
}

How to Practice CSS

Start by changing colors, fonts and spacing on a simple HTML page. Then practice creating buttons, cards and responsive layouts.

What Should You Learn Next?

Once you understand basic CSS, you can start learning JavaScript. JavaScript helps make webpages interactive and dynamic.
